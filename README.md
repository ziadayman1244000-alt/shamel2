# شامل الكينج

موقع الاستعلام عن نتيجة الامتحان الشامل. النسخة دي **static**: مفيش سيرفر ومفيش أوامر.

## فتح الموقع بدون أي أوامر

- على الكمبيوتر: دوس دوبل كليك على `index.html` (أو `docs/index.html`).
- التليفون/التابلت: انقل فولدر `docs` على الجهاز أو افتح لينك GitHub Pages (تحت).

## نشره على GitHub Pages (من الموقع بس)

1. ارفع كل الملفات على الـ repository.
2. افتح **Settings** ← **Pages**.
3. في **Build and deployment** اختار **Deploy from a branch**.
4. اختار الـ Branch: `main` والفولدر: **`/docs`** ← **Save**.
5. بعد دقيقة هيظهر لينك زي `https://USERNAME.github.io/shamel-king/` يفتح على أي جهاز.

## تفعيل إرسال الملاحظات

افتح `client/src/config.ts` وحط رقم واتساب الإدارة (مثال `201012345678`) أو لينك Formspree.
من غير ده زرار الملاحظات هيرد برسالة "مش متفعّل".

## لو عدّلت في الكود

```powershell
npm install -g pnpm
pnpm install
pnpm dev        # تجربة على http://localhost:5173 (وبيطبع لينك للتليفون)
pnpm build      # بيحدّث فولدر docs (لازم ترفعه بعد التعديل)
```
